# График отпусков сотрудников — Казахстан

Небольшое статическое веб-приложение для планирования отпусков трех сотрудников.

## Запуск локально

Откройте файл `index.html` в браузере. Установка зависимостей и сервер не нужны.

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория файлы `index.html`, `README.md` и `.gitignore`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации GitHub Pages покажет ссылку на сайт в этом же разделе.

## Возможности

- три демонстрационных сотрудника;
- основной отпуск 30 календарных дней и экологический отпуск 10 календарных дней;
- деление отпуска на две части;
- проверка пересечений отпусков между разными сотрудниками;
- пересчет даты окончания с учетом списка праздничных дат;
- сводная таблица, помесячная визуализация, экспорт CSV и печать в PDF;
- выбор года планирования.

## Важные примечания

- Данные сотрудников и изменения хранятся только в текущей вкладке браузера; серверного хранения и общей базы данных нет. Скачивайте CSV, чтобы сохранить свой график.
- Список праздничных дат встроен в демонстрационный пример и не является гарантированно полным официальным производственным календарем с учетом всех ежегодных переносов. Перед утверждением графика актуализируйте его по официальным публикациям Республики Казахстан.
- Порядок предоставления экологического отпуска и его продолжительность следует проверить по применимому правовому основанию и документам работодателя.
- Приложение — вспомогательный планировщик, а не юридическое заключение или кадровая система.
